A deterministic program that writes one original one-line office joke: the boss calls a meeting about too many meetings, it runs an hour over, so they schedule a follow-up.

## Run it

```sh
python3 main.py
```

It writes one line of comedy (119 characters) to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
